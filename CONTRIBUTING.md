# Contributing to Orbit AI

Thanks for helping improve Orbit AI. Keep contributions focused, testable, and respectful of user privacy.

## Development

Install dependencies with `npm install`. Run the app with `npm run dev`, the test suite with `npm test`, and the production build with `npm run build`.

## Pull requests

Describe the user-facing outcome, include tests for behavior changes, and avoid committing `.env` files or provider credentials. Changes involving AI providers should preserve the demo-mode fallback and keep secrets on the server.

## Safety

Use only accounts, endpoints, and data you own or are explicitly authorized to test. Do not add functionality for spam, credential theft, evasion, or unauthorized access.
